## Power BI public embedding

The report's **File > Embed report > Publish to web (public)** menu item is disabled in both viewing and editing mode.
The standard toolbar also does not expose an available public publishing action.
The UI does not provide a specific explanation for this disabled item. No public embed code has been generated.
Evidence: `visuals/screenshots/publish_to_web_disabled.jpg`.

[Microsoft's publication prerequisites](https://learn.microsoft.com/en-us/power-bi/collaborate-share/service-publish-to-web)
include the applicable license, report/model permissions, tenant enablement and a supported report configuration.
These prerequisites need to be resolved before the native report can have an anonymous Power BI URL.
The browser walkthrough uses actual report captures and clearly discloses that it is not a live Power BI embed.
